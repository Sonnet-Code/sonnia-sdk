# Sonnia Unity client

The 3D avatar of Sonnia. It connects to the orchestrator over a local WebSocket,
plays the assistant's voice as it streams in, moves the lips from the phonemes of
that audio (uLipSync), animates the avatar for each state (idle, listening,
thinking, speaking), shows subtitles, images and the trivia screen, and walks off
screen in away mode. The contract with the orchestrator is
[`../docs/protocol.md`](../docs/protocol.md); `Assets/Scripts/Sonia/Protocol.cs`
mirrors it.

- Editor: **Unity 6000.6.0f1** (Unity 6.6), URP template.
- Scene: `Assets/Scenes/SampleScene.unity`.
- Scripts: `Assets/Scripts/Sonia/` (namespace `Sonia`), editor tools under
  `Assets/Scripts/Sonia/Editor/` (menu **Sonnia**).
- Input System only: `UnityEngine.Input` throws, use `UnityEngine.InputSystem`.
- Screen: a **vertical 9:16 monitor, 1080x1920**. The scene, the camera framing
  and the HUD are laid out for that format.

## Quick start

1. Open the project with Unity 6000.6.0f1 and let it resolve the packages
   (uLipSync comes from its git repository).
2. Set the Game view to a 9:16 portrait aspect (for example 1080x1920).
3. Start the orchestrator (see the repository README), then press Play. The
   client connects to `ws://127.0.0.1:8765` and reconnects on its own. To use
   another address, launch the app (or the editor) with
   `-sonia-ws ws://127.0.0.1:<port>`.

Without an orchestrator the avatar still idles; it just has nothing to say.

## Avatar

**Default: Sticker.** The scene keeps a disabled copy of "Sticker", from the
[Genies Avatar Starter Pack](https://github.com/geniesinc/GeniesStarterPack)
(`Assets/Avatar/Genies`, permissive license in `Assets/Avatar/Genies/LICENSE.md`).
At startup `AvatarBinder` binds it to the pipeline: animation (`MotionPlayer`,
`AvatarChoreographer`), head and blinking (`AvatarStateController`), eyes
(`EyeGazeController`) and face (`FaceRig`, which maps lip-sync, blinks and
expressions to the Genies FACS blendshapes).

**Optional: Genies Avatar SDK.** The SDK is proprietary and is never committed
(`.gitignore` covers `Packages/com.genies.avatar-sdk.client/`, `Assets/Genies/`,
`Assets/Samples/` and the credentials file `GeniesAuthSettings.bytes`). To use it:

1. Install the Genies Avatar SDK (`com.genies.avatar-sdk.client`) and set up your
   Genies credentials as its documentation explains.
2. Unity then defines `SONNIA_GENIES` (a `versionDefines` entry on that package in
   `Sonia.Genies.asmdef` and `Sonia.Editor.asmdef`) and compiles the `Sonia.Genies`
   assembly, which only builds when the SDK is present.
3. In Play, `GeniesAvatarLoader` is added at runtime and loads the custom avatar
   defined in `Assets/Sonia/Avatar/SoniaGeniesAvatar.json` (the `set_avatar`
   message can replace it). Sticker shows only if the SDK delivers no avatar.
4. Run **Sonnia > Create Motion Set** once: it copies the SDK's own `DefaultIdle`
   and `Walk` clips to `Assets/Animations/GeniesSdk` and prefers them. That folder
   is under the Genies SDK license: do not commit it, and revert the regenerated
   `Assets/Animations/SoniaMotionSet.asset` before committing.

Without the SDK, `set_avatar` is ignored.

## Animations

`Assets/Scripts/Sonia/SoniaAnimations.cs` is the catalog and **Sonnia > Create Motion
Set** builds `Assets/Animations/SoniaMotionSet.asset` from it. Only redistributable
clips are included (sources and licenses in
`Assets/Animations/Genies/LICENSE.md`):

- `Wave` (greeting) and `Peace`, from the Genies Avatar Starter Pack.
- `actions-presentItem_intro` (pointing at an image), `actions-0224-lookAtObject_Trimmed`
  (thinking), `QuickAction_salute`, `QuickAction_twoThumbsUp` and `QuickAction_vibe`
  (attention gestures, dance and trivia reactions), Apache-2.0 from GeniesIRL and
  GeniesCamera.
- `Assets/Animations/Sonnia/SonniaIdle.anim`, the idle loop: generated by the same
  menu (or **Sonnia > Regenerate Idle Clip**) from a still frame of
  `actions-presentItem_intro` with a slow weight shift on top. Breathing, head
  motion, gaze, blinking and hand accents while speaking are procedural.

There is no walk cycle without the Genies SDK: in away mode the avatar slides off
screen instead of walking.

## Screen

`StageScreen` builds the screen in code in Play: the background
(`Assets/Resources/Stage/stage-bg.png`), the "come and talk to me" speech bubble
while nobody is talking, and karaoke-style subtitles. To show a logo in the top
left corner, add `Assets/Resources/Stage/stage-logo.png` (PNG with alpha; an
optional `stage-logo-shadow.png` is drawn behind it). Without it nothing is drawn
there. `TriviaController`, `BusyIndicator`, `AwaySignController` and
`StageParticles` draw the trivia card, the waiting pill, the away sign and the
particles.

## Development controls

The screen normally shows only the avatar and its subtitles. The development
controls (connection and state labels, a text box to type to the assistant, an
"Interrupt" button, F1 for the HUD and F2 for the tuning panel) appear when the app
is launched with `-dev-ui`, or in the editor with **Sonnia > On-screen Developer
Controls**. **Esc** always opens the options menu: graphics quality, microphone,
camera and display, and particles.

Useful editor menus:

- **Sonnia > Create Base Scene**, **Update Components**, **Place Avatar**,
  **Recompute Framing (fallback avatar)** and **Studio Lighting** rebuild parts of
  the scene.
- **Sonnia > Vertical 9:16 Capture** renders the main camera at 1080x1920 (the
  Game view capture tools render 16:9 and are no good for judging the framing).
- **Sonnia > Check Animations (Play mode)** and **Check Screen (Play mode)** save
  captures and a report to check the clips and the screen states.

## Builds

Use Unity's Build Profiles (macOS or Windows, 1080x1920; **Sonnia > Configure 9:16
Build** sets the player resolution). The orchestrator is not packaged: run it
separately. With the Genies SDK, `SoniaPlayerBuildFixes` post-processes macOS
builds (NAF libraries without preload, library paths, ad hoc signing); Windows
machines need the Visual C++ runtime installed.
