# Tecnologías para explicar en 20 segundos

## Kubernetes
> Orquesta contenedores: los reparte entre máquinas, los escala y los levanta solos si se caen.

## Docker
> Empaqueta una aplicación con todo lo que necesita en un contenedor que funciona igual en cualquier máquina.

## Git
> Control de versiones: guarda el historial del código, permite trabajar en ramas y fusionarlas.

## La nube
> Usar servidores, almacenamiento y servicios de otros por internet en lugar de tener máquinas propias.

## Una API
> Un contrato para que dos programas se hablen: uno pide algo con unas reglas y el otro le contesta.

## La inteligencia artificial
> Programas que aprenden de datos para hacer cosas que parecían de personas: entender, ver, hablar o decidir.

## Machine learning
> Aprendizaje automático: en vez de programar las reglas, el sistema las aprende de muchos ejemplos.

## Una red neuronal
> Capas de neuronas artificiales conectadas que ajustan sus pesos con ejemplos hasta aprender una tarea.

## Un modelo de lenguaje
> Una IA entrenada con muchísimo texto que predice la siguiente palabra y así puede conversar y escribir.

## Un agente de IA
> Una IA que no solo contesta: decide pasos y usa herramientas (buscar, ejecutar acciones) para cumplir un objetivo.

## Blockchain
> Un registro compartido entre muchos ordenadores, encadenado y muy difícil de alterar; la base de las criptomonedas.

## La computación cuántica
> Computadoras que usan cúbits, que pueden estar en varios estados a la vez, para ciertos problemas muy difíciles.

## El internet de las cosas
> Objetos cotidianos conectados a internet que miden y se controlan a distancia: bombillas, relojes, sensores.

## El 5G
> La quinta generación de redes móviles: mucha más velocidad y menos retraso que el 4G.

## El wifi
> Conexión a una red sin cables, por ondas de radio, entre tus dispositivos y un router.

## El Bluetooth
> Conexión inalámbrica de corto alcance entre dispositivos cercanos, como auriculares y teléfonos.

## HTML
> El lenguaje de marcas que define la estructura de una página web: títulos, párrafos, enlaces, imágenes.

## CSS
> Las hojas de estilo que dan a una web sus colores, tipos de letra y la colocación de cada cosa.

## JavaScript
> El lenguaje que da vida a las páginas web en el navegador; también corre en servidores.

## TypeScript
> JavaScript con tipos: avisa de muchos errores antes de ejecutar el código.

## Python
> Un lenguaje fácil de leer, muy usado en ciencia de datos, inteligencia artificial y automatización.

## Kotlin
> Un lenguaje moderno y conciso, el recomendado para hacer apps de Android.

## Flutter
> Un framework para hacer apps de móvil, web y escritorio con un solo código, en el lenguaje Dart.

## Android
> El sistema operativo de la mayoría de los móviles del mundo, de código abierto.

## Firebase
> Servicios en la nube para apps: base de datos en tiempo real, usuarios, notificaciones y alojamiento.

## TensorFlow
> Una biblioteca de código abierto para entrenar y usar modelos de aprendizaje automático.

## Una base de datos
> Donde una aplicación guarda sus datos de forma ordenada para buscarlos y cambiarlos rápido.

## SQL
> El lenguaje para consultar y modificar bases de datos relacionales: SELECT, INSERT, UPDATE.

## La ciberseguridad
> Proteger sistemas, redes y datos de ataques, robos y accesos que no deberían pasar.

## El phishing
> Engañar a alguien con un correo o un mensaje que parece legítimo para robarle contraseñas o datos.

## La autenticación en dos pasos
> Además de la contraseña, un segundo paso para entrar: un código en el móvil o una llave física.

## La criptografía
> Cifrar la información para que solo pueda leerla quien tiene la clave.

## Una VPN
> Un túnel cifrado por internet entre tu dispositivo y otra red, para conectarte de forma privada.

## El DNS
> La agenda de internet: traduce nombres como una web a la dirección IP del servidor.

## Un compilador
> Un programa que traduce el código que escribimos al lenguaje que entiende la máquina.

## DevOps
> Unir desarrollo y operaciones: automatizar pruebas, despliegues y monitorización para entregar más rápido.

## La integración continua
> Cada cambio de código se prueba y se integra automáticamente, muchas veces al día.

## Los microservicios
> Una aplicación partida en servicios pequeños e independientes que se hablan entre sí por la red.

## El código abierto
> Software cuyo código puede ver, usar y mejorar cualquiera.

## La realidad aumentada
> Poner objetos digitales encima del mundo real, por ejemplo a través de la cámara del móvil.

## La realidad virtual
> Meterte en un mundo digital en 3D con unas gafas que siguen el movimiento de tu cabeza.

## Un algoritmo
> Una serie de pasos ordenados para resolver un problema, como una receta de cocina.

## El big data
> Manejar y analizar cantidades enormes de datos que no caben en las herramientas de siempre.

## WebAssembly
> Un formato que permite ejecutar en el navegador código de otros lenguajes casi a velocidad nativa.
