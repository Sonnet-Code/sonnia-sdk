# Palabras del Wordle de tecnología

## LINUX
> Sistema operativo libre que corre en casi todos los servidores; su mascota es un pingüino.

## REACT
> Biblioteca para hacer interfaces con componentes, creada por Meta.

## SWIFT
> Lenguaje de Apple para programar apps de iPhone; su logo es un pájaro.

## KAFKA
> Plataforma para mover millones de eventos en tiempo real; lleva el nombre de un escritor.

## REDIS
> Base de datos en memoria rapidísima, muy usada como caché.

## FLASK
> Microframework web de Python: con pocas líneas ya tienes un servidor.

## SCALA
> Lenguaje que corre en la JVM y mezcla objetos con programación funcional.

## JULIA
> Lenguaje para cálculo científico: rápido como C y cómodo como Python.

## RAILS
> Framework de Ruby que popularizó eso de «convención sobre configuración».

## ASTRO
> Framework web que manda casi cero JavaScript y brilla en sitios de contenido.

## REDUX
> Contenedor de estado predecible, el compañero clásico de React.

## GODOT
> Motor de videojuegos libre y ligero; su logo es una carita de robot.

## NGINX
> Servidor web y proxy inverso que reparte el tráfico de medio internet.

## MYSQL
> Base de datos relacional de toda la vida, con un delfín como mascota.

## MONGO
> Base de datos de documentos: guarda JSON en lugar de tablas.

## FIGMA
> Herramienta de diseño en el navegador donde todo el equipo dibuja a la vez.

## SPARK
> Motor para procesar datos masivos en un clúster; en inglés, su nombre es una chispa.

## BABEL
> Traduce el JavaScript moderno a uno que entienden todos los navegadores.

## COBOL
> Lenguaje nacido a finales de los 50 que todavía mueve muchos bancos.

## BASIC
> Lenguaje pensado para principiantes que enseñó a programar a toda una generación en los 80.

## SHELL
> La consola donde escribes comandos para hablar con el sistema operativo.

## CLOUD
> Servidores que alquilas por horas en vez de comprarlos; AWS, Azure y Google los venden.

## PIXEL
> El puntito más pequeño de una pantalla; también un teléfono de Google.

## TOKEN
> La unidad en que los modelos de lenguaje cuentan el texto, y por la que cobran.

## LOGIN
> La pantalla donde pones tu usuario y tu contraseña para entrar.

## CACHE
> Memoria rápida que guarda lo usado hace poco para no tener que pedirlo otra vez.

## QUERY
> Consulta que le haces a una base de datos, por ejemplo con SQL.

## ARRAY
> Lista ordenada de elementos cuyo índice empieza en cero.

## STACK
> Pila: lo último que entra es lo primero que sale; también, las tecnologías de un proyecto.

## FLOAT
> Tipo de dato para guardar números con decimales.

## PROXY
> Intermediario que hace las peticiones en tu nombre y esconde de dónde vienen.

## MODEM
> Aparato que conecta tu casa a internet; en los 90 hacía ruiditos al marcar.

## DEBUG
> Buscar y arreglar los errores del código, paso a paso.

## BUILD
> Compilar y empaquetar el proyecto para dejarlo listo para publicar.

## MERGE
> Juntar los cambios de dos ramas de Git en una sola.

## PATCH
> Arreglo pequeño que se publica para corregir un fallo.

## ALPHA
> Primera versión de prueba de un producto, antes de la beta.

## AGILE
> Forma de trabajar por ciclos cortos, con sprints y retrospectivas.

## SCRUM
> Marco de trabajo ágil con sprints y reuniones diarias de pie.

## CRASH
> Cuando la aplicación se cierra de golpe y sin avisar.

## CLICK
> Lo que haces con el dedo sobre el ratón para pulsar un botón.

## MOUSE
> Lo mueves con la mano para llevar el cursor por la pantalla.

## ROBOT
> Máquina programada para hacer tareas sola, como las de una fábrica.

## DRONE
> Aparato volador sin piloto, con cámara y varias hélices.

## EMOJI
> Las caritas y los dibujitos que mandas por WhatsApp.

## MODEL
> Lo que una IA aprende al entrenarse con montones de datos.

## AGENT
> Programa de IA que decide y ejecuta tareas por su cuenta, y no solo responde.

## VIRAL
> Lo que se comparte tanto en redes que acaba viéndolo medio mundo.

## ERROR
> Lo que sale en rojo cuando algo no funciona.

## INDEX
> Lo que acelera las búsquedas en una base de datos, como el de un libro.

## FETCH
> Función de JavaScript para pedirle datos a un servidor; en inglés, «ir a buscar».

## LLAMA
> Familia de modelos de lenguaje abiertos de Meta; también un animal de los Andes.

## GEMMA
> Modelos de lenguaje abiertos y pequeños de Google.

## COLAB
> Cuadernos de Python en la nube de Google, con GPU gratis.

## GMAIL
> El correo de Google, con un sobre rojo y blanco como logo.

## DRIVE
> Donde guardas y compartes archivos en la nube de Google.

## SLACK
> App de chat para equipos de trabajo, con canales y mil integraciones.

## ASYNC
> Palabra clave que deja esperar un resultado sin bloquear el programa; va junto a await.

## CLASS
> El molde con el que se crean objetos en la programación orientada a objetos.

## STATE
> Los datos que cambian en una app y hacen que la pantalla se redibuje.

## PROPS
> Los datos que un componente de React recibe de su padre.

## HOOKS
> Funciones de React cuyo nombre empieza por use, como useState.

## WHILE
> Bucle que se repite mientras se cumpla una condición.

## FALSE
> Lo contrario de true: el valor booleano que significa no.

## PRINT
> La instrucción clásica de casi todos los lenguajes para sacar texto por pantalla.
